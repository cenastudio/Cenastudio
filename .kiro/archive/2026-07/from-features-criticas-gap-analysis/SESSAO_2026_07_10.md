## 🎯 Como Testar

### Webhooks (Tasks 8-11)

#### Via Interface:
1. Acesse: Settings → Integrações → Webhooks
2. Clique "Novo Webhook"
3. Use URL de teste: `https://webhook.site/unique-id`
4. Selecione eventos (ex: "Projeto criado", "Cliente aprovou")
5. Salve e **copie o secret** (mostrado uma vez)
6. Clique botão "Testar" → verifique recebimento em webhook.site
7. Crie um projeto novo → webhook dispara automaticamente

#### Validar Signature (lado receptor):
```javascript
const crypto = require('crypto');

const receivedSignature = req.headers['x-webhook-signature'];
const secret = 'seu-secret-uuid'; // do Cena Studio
const payload = JSON.stringify(req.body);

const expectedSignature = crypto
  .createHmac('sha256', secret)
  .update(payload)
  .digest('hex');

if (receivedSignature !== expectedSignature) {
  return res.status(401).send('Invalid signature');
}
```

#### Payload Exemplo:
```json
{
  "event": "project.created",
  "timestamp": "2026-07-10T12:00:00.000Z",
  "userId": 123,
  "projectId": 456,
  "data": {
    "projectName": "Reel Instagram",
    "status": "active"
  }
}
```

## 💡 Decisões Técnicas

### Webhooks
- **HMAC-SHA256** escolhido para signature (padrão indústria)
- **Cron job** ao invés de Bull/Redis (zero custo adicional)
- **10s timeout** com AbortController (previne lock)
- **Backoff exponencial** 10s/30s/90s (evita sobrecarga)
- **Fire-and-forget** dispatch (não bloqueia operação principal)

### Asset Library
- **Soft delete** ao invés de hard delete (preserva URLs)
- **Multer memory storage** (adequado para 50MB limite)
- **Cloudinary transformations** para thumbnails (automático)
- **BigInt** para file sizes (suporta >2GB no futuro)
