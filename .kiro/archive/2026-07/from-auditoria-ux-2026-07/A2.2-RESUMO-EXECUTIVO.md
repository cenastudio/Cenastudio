# A2.2 — Resumo Executivo: Confirmação de Visibilidade de Abas

## TL;DR

**A premissa do requisito está incorreta.** O mobile NÃO mostra "apenas 3 abas" — ele renderiza todas as 5 abas, mas apenas 2 são visíveis sem scroll horizontal.

## Achados principais

| Viewport | Abas no DOM | Abas visíveis sem scroll | Necessita scroll |
|----------|-------------|--------------------------|------------------|
| Desktop 1280px | 5 | 5 | ❌ Não |
| Tablet 768px | 5 | 5 | ❌ Não |
| Mobile 375px | 5 | 2 | ✅ Sim (horizontal) |

## Problema de UX identificado

No mobile (375px):
- ✅ **Paridade funcional existe** (todas as 5 seções acessíveis)
- ❌ **Descobribilidade ruim** (scrollbar oculto com `scrollbar-none`)
- ❌ **Não atende critério de ≤2 toques** para abas 3-5 (requer scroll + toque)

## Impacto para tarefa A2.3

A tarefa A2.3 deve implementar uma solução para **melhorar a descobribilidade** das abas 3-5 no mobile, não "torná-las acessíveis" (elas já são acessíveis via scroll).

## Recomendações de solução (para A2.3)

### Opção 1: Menu overflow "Mais" ⭐ RECOMENDADO
- Mostrar as 2-3 primeiras abas diretamente
- Colocar as restantes em dropdown "Mais" (ícone ⋯)
- **Atende critério de ≤2 toques**
- Padrão reconhecido em mobile

### Opção 2: Migrar para ResponsiveTabs
- Usar componente existente `client/src/components/ui/responsive-tabs.tsx`
- Consistente com outras páginas (AdminDashboard, ClientDetail)
- **Precisa verificar suporte para navegação entre rotas**

### Opção 3: Indicador visual de scroll
- Adicionar gradiente de fade nas bordas
- Snap scroll entre abas
- Dots indicator
- **Não elimina o scroll horizontal (solução de meio-termo)**

## Código analisado

**Componente:** `client/src/components/CommercialNav.tsx`

```tsx
const COMMERCIAL_TABS = [
  { href: "/commercial",    labelPt: "Visão geral", ... },
  { href: "/clients",       labelPt: "Clientes",    ... },
  { href: "/pipeline",      labelPt: "Pipeline",    ... },
  { href: "/proposals",     labelPt: "Propostas",   ... },
  { href: "/interactions",  labelPt: "Interações",  ... },
] as const;

// Todas as 5 são sempre renderizadas:
<div className="flex items-center overflow-x-auto scrollbar-none">
  {COMMERCIAL_TABS.map((tab) => ...)}
</div>
```

**Não há lógica condicional de renderização baseada em viewport.**
